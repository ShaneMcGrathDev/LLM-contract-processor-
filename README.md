#   🚀 LLM contract processing tool


### Overview
This is a full stack application designed to process contracts into structured format leveraging LLM APIs. 



## ✅ Project Directory Quick Reference 

- ⚛️ Next.js Frontend 
- 🐍 Flask Backend/REST API 
- 🎯 CRUD operations  
- 🤖 Claude API
- 🐳 Docker Compose
- 💾 PostgreSQL database (Via Supabase platform)
- 🎨 Shadcn UI Library
